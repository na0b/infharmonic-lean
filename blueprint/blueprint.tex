\title[Blueprint of the Lean formalization]{Uniform interior $C^{1,\alpha}$ estimates for infinity-harmonic functions: blueprint of the Lean formalization}
\author{Juan J. Manfredi}

\begin{document}
\begin{abstract}
This document collects the natural-language statements and detailed proofs that accompany the Lean~4 formalization of the main results of OpenAI, \emph{Uniform Interior $C^{1,\alpha}$ Estimates for Infinity-Harmonic Functions}, OpenAI Math Release preprint, October~4, 2026.
The mathematics is that of the preprint; this document only reorganizes it into the units of the formalization.
Each subsection corresponds to the Lean declaration of the same name in the directory \texttt{InfHarmonic/}; cross-references point to the results that a proof uses.
Section~\ref{sec:main} lists the formalized results of the paper: Theorem~1.1, Corollary~1.2 and Theorem~3.1.
Within each section, items appear in dependency order.
\end{abstract}
