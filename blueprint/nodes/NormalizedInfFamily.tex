\begin{definition}[The normalized family $\mathcal U$]
Fix an integer $d\ge1$ and put $n=d+1$, identifying $\R^n$ with the space-time
$\ell^2(\R^d\times\R)$ of the preamble and writing $e_b=(0,1)$ for the added
unit direction. A function $U$ on $\R^n$ belongs to the \emph{normalized family
$\mathcal U$} if there is a function $u:\R^d\to\R$ such that
\begin{enumerate}
\item $u$ is continuous and infinity-harmonic on $B_1^d$ in the sense of
\noderef{IsInfHarmonicOn};
\item $u(0)=0$, the set $u(B_1^d)$ is bounded above and below, and
$\osc_{B_1^d}u\le1$, the oscillation being that of \noderef{OscOn};
\item $U(y,b)=u(y)+b$ for every $(y,b)\in\R^d\times\R$.
\end{enumerate}
\end{definition}
